# Yash Khairwal — Studio V3 Portfolio

This branch contains the current cinematic portfolio published at:

**https://yash-khairwal-studio-v2-2026.stony-gull-0511.chatgpt.site/**

## Run locally

This is a static HTML/CSS/JavaScript site. No installation or build step is needed.

```bash
python -m http.server 8000
```

Open http://localhost:8000/ in your browser.

## Project structure

- `index.html` — main portfolio layout and case studies.
- `css/` — design system, visual effects, responsive styling.
- `js/` — scene animations, transitions, and project interactions.
- `assets/` — original project captures, portfolio imagery, and static resources.
- `vendor/` — local copies of third-party browser modules.

The portfolio describes PromptForge, DO, FinPulse X, and SteadyNest. Simulations and illustrative data are labelled in the interface and should not be described as real transactions or deployed systems.
